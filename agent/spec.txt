Project: Car Inventory Manager - Frontend UI Components

Context: The core state management and GraphQL integration have been implemented in the boilerplate (`App.tsx`, `useCars.ts`, `queries.ts`). 
Your task is to implement the UI presentation layer by generating the required React components.

Component Architecture:

1. CarCard Component (`src/components/CarCard.tsx`)
- Export: Named export `CarCard`.
- Props: Accepts `make`, `model`, `year`, `color`, `mobile`, `tablet`, and `desktop`.
- UI: Use Material UI `<Card>` to display the vehicle details. 
- Responsiveness: Map the image URLs directly to MUI `sx` breakpoints for the background image (xs: mobile, sm: tablet, md: desktop).

2. CarControls Component (`src/components/CarControls.tsx`)
- Export: Named export `CarControls`.
- Props: `onApplySearchSort: (term: string, sort: string) => void` and `addCar: (newCar: { make: string, model: string, year: number, color: string }) => Promise<void>`.
- Internal State: Use React `useState` to manage draft inputs for search (string) and sort (string: 'year' or 'make').
- UI Elements:
  - Text input for model/make search.
  - Select dropdown for sorting.
  - "Apply" button that triggers `onApplySearchSort` with the current draft states.
  - "Add New Car" button that opens a MUI `<Dialog>`.
- Dialog Form: Ensure the modal contains exactly 4 TextFields: Make, Model, Year, and Color. Submission should await `addCar`, clear the form, and close the dialog.

Technical Constraints:
- Use standard React hooks (useState). Avoid external form libraries like Formik to reduce bundle size.
- Restrict modifications to the `src/components/` directory. Rely on the existing `App.tsx` and `useCars.ts` for logic.
